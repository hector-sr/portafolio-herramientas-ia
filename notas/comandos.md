# Comandos que aprendí


| Comando | Para qué sirve |
|---|---|
| `pwd` | Saber en qué carpeta estoy |
| `ls` | Listar los archivos y carpetas del directorio actual |
| `cd` | Cambiar de carpeta en la terminal |
| `git init` | Convertir una carpeta en repositorio |
| `git status` | Ver el estado de los archivos en el repositorio |
| `git add` | Preparar cambios para el commit |
| `git commit -m` | Guardar una foto con un mensaje |
| `git pull` | Descargar y fusionar los cambios desde GitHub |
| `git push` | Subir los commits locales al repositorio de GitHub |
| `git clone` | Descargar una copia del archivo/carpeta/repositorio de GitHub a la pc (clonarlo) |
